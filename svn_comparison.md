1. Почему в Git ветвление «дешевое», а в SVN — «дорогое»?
В Git: Ветка — это просто текстовый файл весом в 41 байт, содержащий хэш-ссылку на коммит. Создается мгновенно.
В SVN: Ветка — это физическое копирование папки внутри репозитория на сервере. Чем больше проект, тем тяжелее и дольше операция.
2. Можно ли в SVN сделать коммит без интернета?
Нет.
Почему: В SVN архитектура централизованная. База данных с историей всего одна и находится на сервере. Без сети клиенту просто некода отправлять изменения.
3. Когда SVN все еще лучше, чем Git?
Огромные бинарные файлы: Игры (3D-модели, текстуры) или дизайн-проекты. Git ломается на терабайтах бинарников, а SVN качает только нужные папки, а не всю историю.
Строгий доступ (Locking): Когда над файлом может работать строго один человек (например, дизайнер блокирует файл, пока его правит), чтобы избежать конфликтов.
Частичное скачивание: В SVN можно скачать одну конкретную подпапку из огромного проекта, в Git приходится клонировать весь репозиторий целиком.
